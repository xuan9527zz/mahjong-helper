# 广东麻将防点炮训练器

一个无需安装、可直接部署到 GitHub Pages 的静态网页，用牌河、副露、过胡窗口和包三家风险训练弃牌判断。

## 当前功能

- 模拟练习：三道结构演示题、四个弃牌候选、即时风险复盘
- 实战推测：从手牌选择候选，调整三家牌型、主色、听牌可能、落地张数与过胡牌
- 盘面编辑：录入自己的手牌及三家牌河
- 风险模型：分别计算三家点炮可能，再按牌值与包三家放大计算预期损失
- 广东规则约束：不把自己打过的牌视为永久安全；过胡仅在下一次摸牌前有效

## 本地查看

```bash
npm run serve
```

然后打开 `http://localhost:4173`。

## 验证

```bash
npm test
```

## 添加新题

题目都放在 `js/questions.js`。复制一个题目对象并修改以下字段即可：

- `self.hand`：自己的 14 张手牌
- `opponents`：三家的牌河、副露和风险信号
- `candidates` / `answerTile`：四个候选与作者答案
- `evidence` / `explanation`：题面事件与复盘说明

测试会检查候选是否在手牌中，并确认作者答案与通用风险模型的最低预期损失一致。

> 当前百分比是用于同一盘面比较的训练模型估计，并非基于真实牌局样本校准的统计概率。
